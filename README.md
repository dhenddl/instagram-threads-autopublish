# instagram-threads-autopublish

**개발자 한 명이 4주 동안 사람 손 안 대고 인스타그램·스레드에 발행한 파이프라인 전체입니다.**

카드뉴스와 릴스를 코드로 만들고(`cardnews/`), Graph API로 **인스타그램 캐러셀과 스레드에 동시 발행**하고(`publish/`), 성과를 API로 읽어옵니다(`check-insights.mjs`). 예약까지 걸면 발행 시점에 사람이 할 일은 없습니다.

---

## 4주 실측 — 잘된 것과 안 된 것을 같이 적습니다

| 형식 | 최고 도달 |
|---|---|
| 릴스 | **178** |
| 스레드 | **3,061** |
| 피드 캐러셀 | **2** |

같은 콘텐츠를 3형식으로 같은 날 낸 적이 있는데 **릴스 132 / 스레드 15 / 피드 캐러셀 2**였습니다. 캐러셀은 3주 내내 한 자릿수였습니다.

그리고 캡션 유무로 릴스 도달이 갈렸습니다 — **캡션 없음 11·2 vs 캡션 있음 100·116·132·132·174·178.** 겹치는 구간이 하나도 없었습니다. (n=8이라 가설입니다.)

**이 저장소는 "잘 되는 법"이 아니라 "제가 4주 동안 실제로 돌린 것"입니다.** 안 된 것도 그대로 뒀습니다.

---

## 뭐가 되나

- `slides.json` → Playwright → **1080×1350 카드뉴스 PNG/JPEG**
- **termcast** — 터미널 화면을 녹화한 것처럼 만드는 릴스
- **움직이는 캐러셀** — 캔바 없이 코드로
- 캡션·해시태그 자동 생성
- **인스타그램 캐러셀 + 스레드 동시 발행** (한 번의 명령)
- **스레드 셀프 답글 체인** (본문 → 답글1 → 답글2 연쇄)
- alt 텍스트 자동 부착
- **성과 조회** — 인스타·스레드 인사이트를 명령 한 줄로 (읽기 전용)
- 60일 토큰 자동 갱신

## 필요한 것

- Node.js
- **인스타그램 프로페셔널 계정 + 공개 계정** (비공개는 API가 안 붙습니다)
- GitHub 계정 (이미지 호스팅용 저장소 1개)
- Claude Code / Codex 같은 코딩 에이전트 (없어도 되지만 있으면 훨씬 빠릅니다)

## ⚠️ 먼저 알아두실 것 — 코드는 쉽고 토큰이 어렵습니다

붙여넣으면 바로 도는 코드가 아닙니다. **가장 오래 걸리는 건 Meta 쪽 설정입니다.**

- 인스타그램 프로페셔널 + 공개 계정 전환
- Meta 개발자 앱 생성 → Instagram 로그인 API 설정 → **장기 토큰(60일) 발급**
- Threads는 **별도 토큰**
- 이미지 호스팅용 GitHub 저장소

여기서 막히는 지점들과 제가 실제로 겪은 오류(거짓 실패 응답, 토큰 만료, 렌더 중단 등)는 **아래 가이드 문서**에 증상 → 원인 → 해결로 정리해뒀습니다.

📄 **[전체 가이드 (0~9장) — 준비부터 성과 측정까지](https://www.notion.so/3b474fbdd72681de80b4c81d851743bc)**

특히 **5장 "막힌 지점 전부"** 에 제가 실제로 걸린 14건을 증상 → 원인 → 해결 3줄로 적어뒀습니다. 코드보다 그쪽이 오래 걸립니다.

## 빠른 시작

```bash
# 1) 카드뉴스 렌더링
cd cardnews
npm install && npx playwright install chromium
node render.js            # slides.json -> out/ 에 이미지 생성

# 2) 발행 설정
cd ../publish
cp .env.example .env      # 값 채우기 (위 "필요한 것" 참고)

# 3) 먼저 dry-run 으로 확인 — 실제 발행 직전에 멈춥니다
node publish.mjs --manifest post-insights-api.json --dry-run

# 4) 실제 발행
node publish.mjs --manifest post-insights-api.json

# 5) 성과 조회 (읽기 전용)
node check-insights.mjs
```

**반드시 `--dry-run` 을 먼저 돌리세요.** 발행은 되돌릴 수 없습니다.

## 구조

```
cardnews/
  render.js            슬라이드 JSON -> 카드뉴스 이미지
  make-termcast.mjs    터미널 녹화형 릴스
  make-reels.mjs       릴스 렌더링
  make-making-of.mjs   제작 과정 영상
  reel-caption.mjs     캡션·해시태그 생성
  slides.json          입력 예시

publish/
  publish.mjs          인스타 캐러셀 + 스레드 동시 발행 (dry-run 지원)
  host.mjs             GitHub raw 이미지 호스팅
  host-mixed.mjs       이미지+영상 혼합 호스팅
  check-insights.mjs   인스타 성과 조회 (읽기 전용)
  check-threads-insights.mjs  스레드 성과 조회 (읽기 전용)
  alt.mjs              alt 텍스트
  refresh-tokens.mjs   60일 토큰 갱신
  run-publish.cmd      작업 스케줄러용 실행 스크립트
  post-insights-api.json   매니페스트 샘플 (실제로 발행된 글입니다)
```

⚠️ 예약은 **Windows 작업 스케줄러** 기준으로 짜여 있습니다(`run-publish.cmd`). 맥·리눅스면 cron으로 바꿔주세요.

## 주의사항

- **플랫폼 정책을 지키세요.** 자동화가 허용되는 건 **사용자가 먼저 행동했을 때**(댓글·스토리 답장 등)입니다. **콜드 DM, 자동 팔로우/언팔로우, 자동 좋아요는 정책 위반**이고 계정이 제한될 수 있습니다.
- 이 저장소는 **본인 계정에 본인 콘텐츠를 발행**하는 용도입니다.
- 토큰은 60일마다 만료됩니다. `refresh-tokens.mjs`를 주기적으로 돌리세요.
- 성과 조회 스크립트는 **읽기 전용**입니다. 쓰기 동작이 없습니다.
